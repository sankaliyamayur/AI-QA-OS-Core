# User Story Analysis Skill

Guidance for parsing and analyzing enterprise User Story specifications:

## Metadata Extraction Rules
1. Extract Story ID (e.g. US-ONEPURPOS-LOGIN-001), Story Title, Module, Priority, and Application Details (URL, Credentials, Environment).
2. Extract all Acceptance Criteria (AC-001 through AC-N) verbatim.
3. Extract Business Rules, Functional Requirements, and Validation Rules.
4. Categorize test scenarios into Positive, Negative, Edge, and Security buckets.
5. Flag any underspecified requirements or ambiguous validation logic.
