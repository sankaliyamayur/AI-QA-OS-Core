# Evidence Collection Skill

Guidelines for preserving test execution evidence:

## Evidence Types
1. **Screenshots**: Capture full-page screenshots on failure and key step checkpoints.
2. **Trace Files**: Preserve Playwright trace ZIP files for post-run debugging.
3. **Console Logs**: Capture browser console warnings and errors.
4. **Network Har**: Record HTTP requests and responses for API validation.
