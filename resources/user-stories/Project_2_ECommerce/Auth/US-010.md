Story Title

Customer Login & Cart Access

Module

ECommerce Authentication

Priority

High

Story Description

As a registered Customer,
I want to log in to the E-Commerce Store using my customer credentials,
So that
I can manage my shopping cart and proceed to checkout securely.

Business Rules
Only registered customers can access the checkout pipeline.
The user must navigate to the staging e-commerce portal.
The login modal must open upon clicking the Account icon.
The cart items must sync across customer sessions.

Acceptance Criteria Summary
Total Acceptance Criteria: 5 (AC-010-1 to AC-010-5)

AC-010-1

Given the customer opens the E-Commerce Store URL

When the storefront loads

Then the header logo, search bar, and cart badge should be visible.

AC-010-2

Given the storefront is loaded

When the customer clicks the Account icon

Then the customer authentication drawer should open.
