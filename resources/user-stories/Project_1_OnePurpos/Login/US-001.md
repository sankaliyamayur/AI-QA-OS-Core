Story Description

As a registered User,
I want to log in to the OnePurpos application using my registered email address and password,
So that
I can securely access my account and use the authenticated features available in the application.

Business Rules
Only registered users with valid credentials can successfully log in.
The user must first open the OnePurpos application URL.
The user must click the Login dropdown/menu to access login options.
The user must select the Log in option from the Login dropdown.
Selecting Log in should open the Login side drawer.
Both Email and Password fields are mandatory for login.
Email must be in a valid email format.
Password is case-sensitive.
Successful login should authenticate the user and create a valid user session.
Invalid credentials should not allow the user to log in.
Appropriate validation or error messages should be displayed when login fails.
The Forgot Password link should be available in the Login drawer.
Clicking Forgot Password should successfully navigate the user to the Forgot Password page or password recovery interface.
Functional Requirements

The user should start the login process by opening the exact application URL:

https://onepurpos.in/openings

https://onepurpos.in/openings
